# Prepare a comparative figure

[Research exhibits and presentations](../meso-research-exhibits/SKILL.md) · [Related micro rule](../../micro-skills/draw-comparison-figure/SKILL.md)

**Use when** — Prepare or revise a figure whose panels or series are meant to be read together.

**Correction behind the workflow** — Shared series need consistent labels and styling. A figure can look legible in isolation and become unreadable in the manuscript.

**Begin** — Run only after the person selects this task for the current request. A suggestion alone ends at the suggestion.

1. Identify the intended comparison and where readers will see it. Check the plotted quantities, units, and which panel titles or captions the surrounding document already provides.
2. Build the figure with consistent encodings for the same series. Share a legend when its entries have the same meaning. Choose scales that support the intended comparison and label any necessary difference.
3. Render the assembled figure at its intended size. Read a value from each panel, match each series to its legend, and inspect labels for clipping, duplication, and inconsistent text size. Make one targeted layout correction and render again only if a check fails.

**Deliver and stop** — Deliver the figure with the final-size check result. If only a standalone rendering is available, identify what remains to check in the assembled document. This run permits one initial pass and at most one targeted correction and recheck. A further round or another workflow needs a fresh human choice.

**Stay asleep for** — Apply a single specified label edit, or choose an estimator.
