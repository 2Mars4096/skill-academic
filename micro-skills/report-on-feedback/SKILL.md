# Report progress against feedback

Shared rules · [Professional communication and follow-up](../professional-communication/SKILL.md)

**Use when** — Explain what changed after a set of comments or requests.

**Do** — Group overlapping comments under a short topic. Give each substantive request a concrete disposition and name the change, evidence, or next action. Use plain language a collaborator can scan.

**Don’t** — Bury an unresolved comment under a general claim that the topic was addressed.

**Check** — The reader can locate every substantive request and tell which items still need work.

**Stay asleep for** — Extract decisions from a meeting with no implementation update.
