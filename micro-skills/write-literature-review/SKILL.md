# Write a literature review

Shared rules · [Academic manuscripts](../academic-writing/SKILL.md)

**Use when** — Position a study in the relevant literature.

**Do** — Organize papers around substantive questions. State what each close paper establishes, then identify what remains open and how the study addresses it. When the user supplies a closed bibliography, work within it.

**Don’t** — Add outside citations to a closed set or claim a gap solely because the supplied papers omit a topic.

**Check** — The reader can connect each contribution to a specific strand of prior work.

**Stay asleep for** — Find candidate papers and return a shortlist only.
