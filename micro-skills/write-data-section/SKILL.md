# Write a paper’s data section

Shared rules · [Academic manuscripts](../academic-writing/SKILL.md)

**Use when** — Describe data sources, sample construction, or variables in a manuscript.

**Do** — Introduce sources briefly, then explain construction before sample counts. Order classifications and definitions before the steps that use them. Define each used measure in one appropriate place across the text and appendix, retaining its essential denominator, transformation, and treatment of missing or zero values.

**Don’t** — Repeat source descriptions in variable definitions, duplicate the main text in the appendix, or define variables that the analysis never uses.

**Check** — A reader can reconstruct an observation and its main measures without encountering an undefined term or searching repeated definitions.

**Stay asleep for** — Evaluate whether to acquire a potential dataset.
