# Draw a comparative figure

Shared rules · [Research exhibits and presentations](../research-exhibits/SKILL.md)

**Use when** — Plot estimates or related series in one or more panels.

**Do** — Preserve the established plotting software and visual style during a layout edit. Keep color meanings consistent. Place a shared legend below comparable panels when it fits. In LaTeX, assign panel labels with subcaptions and put notes in a separate minipage. Inspect font size and spacing in the compiled document.

**Don’t** — Redraw an established figure in a new style for a font adjustment, repeat panel titles inside the plot, or embed manuscript notes in the graphic.

**Check** — At final size the axes, legend, and panels are readable, correctly aligned, and consistent with related exhibits.

**Stay asleep for** — Specify the estimator that will produce the coefficients.
