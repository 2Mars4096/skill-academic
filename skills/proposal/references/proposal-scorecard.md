# Proposal Scorecard

Use this when deciding whether an idea is ready for drafting.

Score each dimension from 1 to 5.

## Dimensions

### 1. Question Sharpness

- `1`: topic only
- `3`: question exists but still broad or double-barreled
- `5`: one precise, researchable question

### 2. Contribution Clarity

- `1`: unclear why this adds anything
- `3`: plausible contribution but not yet distinct
- `5`: clear gap relative to a named benchmark

### 3. Data Feasibility

- `1`: data is speculative
- `3`: source is named but construction burden is uncertain
- `5`: source, access path, and key construction tasks are clear

### 4. Identification or Evidence Quality

- `1`: no convincing evidence path
- `3`: plausible but fragile comparison
- `5`: clean and defensible design or descriptive evidence plan

### 5. Execution Burden

- `1`: unrealistic for the user's time or skill constraints
- `3`: feasible but costly or technically demanding
- `5`: manageable next steps and realistic first results

### 6. Interpretation Value

- `1`: even a result would teach little
- `3`: results would be somewhat informative
- `5`: positive, null, and mixed findings would all teach something meaningful

## Decision Rule

- `4.0+`: draft the proposal
- `3.0 to 3.9`: keep developing, but only after naming the weak dimensions
- `below 3.0`: do not draft; narrow, pivot, or park
