# Meso-skills

Resolve this file to its real path if installed through a link. Open the [category and task map](../README.md).

**Suggest** — Identify the deliverable in the current request. Read its category and offer at most one task. Say what it would produce, the check it adds, and the pass limit. If the work is a single edit, say that direct execution is sufficient. A suggestion request ends with the recommendation.

**Run once** — A person can name a task directly or accept the specific suggestion. Open only that task card. If several tasks are plausible and the choice changes the deliverable, present the distinction and let the person choose. A general request to help, a task match, or the selection of a category is insufficient to start a run.

**Stop** — Return the requested output at the card’s stopping point, including an unresolved check when necessary. Never start another round or chain into another card on the strength of a match. The person can request a new run. Selecting a draft applies it only to this request.
