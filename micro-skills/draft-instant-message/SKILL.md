# Draft an instant message

Shared rules · [Professional communication and follow-up](../professional-communication/SKILL.md)

**Use when** — Write a short chat message to coordinate with someone.

**Do** — Return one sendable message. For scheduling, use the proposed times and give the reason for meeting in one natural phrase. Match the greeting to the relationship.

**Don’t** — Inflate a chat request into an email or invent availability.

**Check** — The recipient can answer the request directly in a single reply.

**Stay asleep for** — Write a formal follow-up email after an introduction.
