# Choose the next empirical test

[Empirical code and data](../meso-empirical-analysis/SKILL.md) · [Related micro rule](../../micro-skills/empirical-analysis/SKILL.md)

**Use when** — A descriptive pattern or baseline is in hand and the next analysis depends on what it showed.

**Correction behind the workflow** — A challenged interpretation can require tracing a measure back through its components before choosing another regression. The strength of the estimate must carry through to the explanation.

**Begin** — Run only after the person selects this task for the current request.

1. Read the preceding analytical question and the result it produced. Restate the actual comparison, magnitude, sample, and uncertainty. When the user challenges an interpretation, identify the exact finding it depends on and verify that the estimate supports that claim.
2. If the puzzle concerns a constructed measure, trace its definition to its components and source variables. For a ratio, inspect the numerator and denominator separately and identify which change could produce the observed pattern. Follow that trace only far enough to formulate a testable explanation.
3. Choose one next comparison from that evidence. State which possible outcomes would support each explanation and which would remain ambiguous. Carry through the established baseline controls and sample conventions when comparing regressions, and explain a necessary departure. A request for thoughts or a plan ends with this proposal.
4. When execution is requested and inputs are available, run the selected comparison and inspect the result against those predictions. If the estimate is imprecise, retain that uncertainty in the explanation. Record null or contrary evidence as part of what was learned. Correct a demonstrated implementation error once if needed, then return the updated interpretation and stop.

**Deliver and stop** — Return the starting evidence, why this test was chosen, what was learned or would be learned, and the decision it informs. Stop after this step. A possible subsequent test can be named for human selection. Allow at most one targeted correction and recheck. Another round or workflow requires a fresh human choice.

**Stay asleep for** — Run a prespecified model variation, launch a specification sweep, or screen new research topics.
