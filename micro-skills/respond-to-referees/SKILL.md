# Address referee comments

Shared rules · [Academic manuscripts](../academic-writing/SKILL.md)

**Use when** — Prepare a response or revise a paper against a referee’s concern.

**Do** — Locate the exact concern and inspect what the paper already does to address it. When the request is to improve the response or exposition, first clarify or reposition the relevant definition, design explanation, and existing result. Answer politely, point by point, with a specific manuscript location.

**Don’t** — Treat every referee concern as a request to run additional analysis or claim that clearer wording resolves a remaining evidentiary gap.

**Check** — The response explains what addresses the concern, where the reader can verify it, and any evidence still missing.

**Stay asleep for** — Write an independent report as a referee.
