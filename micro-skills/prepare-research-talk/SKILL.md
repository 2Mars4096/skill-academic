# Prepare a research talk

Shared rules · [Research exhibits and presentations](../research-exhibits/SKILL.md)

**Use when** — Adapt a paper or data analysis for an audience and speaking time.

**Do** — Organize the existing material around the questions the audience needs answered. During a reorganization, use the supplied results. Order appendix slides to follow the corresponding main-deck topics. Use clear visual examples and readable type for data explanations.

**Don’t** — Add new analysis to a slide-reorganization request or substitute a divider slide for organizing the appendix.

**Check** — The audience can follow the main argument and find its supporting appendix material in the same order.

**Stay asleep for** — Give an oral summary without preparing or revising slides.
