# Academic manuscripts

**Use when** — Draft or revise scholarly prose for an empirical paper.

**Do** — Write for a reader encountering the paper for the first time. Define a term where it first does work, use its short name consistently, and let the preceding paragraph motivate the next question.

**Don’t** — Add editorial commentary, defensive asides, or a closing sentence that repeats the paragraph.

**Check** — Each paragraph advances the argument and the same concept keeps the same name.

**Stay asleep for** — Run the underlying analysis without drafting or reviewing prose.
