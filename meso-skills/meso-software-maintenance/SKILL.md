# Software implementation and maintenance

[Meso-skill map](../README.md) · [Micro-skill category](../../micro-skills/software-maintenance/SKILL.md)

**Use when** — Establish whether a reported failure is resolved in the affected workflow.

**Suggest** — Use the bug verification pass when a lower-level check could succeed while the original user action still fails.

- [Verify a reported bug fix](../meso-verify-reported-bug/SKILL.md) — Reproduction check.

**Stay asleep for** — A feature proposal with no reported failure calls for a different task.

**Stop** — Return at most one suggestion, its expected output, and its pass limit. A category selection opens a menu. Only an explicit choice of a task starts that task.
