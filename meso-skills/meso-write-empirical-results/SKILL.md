# Write an empirical results section

[Academic manuscripts](../meso-academic-writing/SKILL.md) · [Related micro rule](../../micro-skills/write-empirical-results/SKILL.md)

**Use when** — Turn a finished set of estimates into a section that explains what the reader learns.

**Correction behind the workflow** — A sign alone leaves the magnitude and comparison unclear. Each additional test should answer a question the preceding evidence leaves open.

**Begin** — Run only after the person selects this task for the current request. A suggestion alone ends at the suggestion.

1. Read the actual exhibit and its specification. Identify the outcome scale, comparison group, reference period where relevant, and uncertainty for the main estimate.
2. Draft the motivating comparison and translate the main estimate into the effect of a meaningful change in the original units when that translation is supported. Explain what the next exhibit helps distinguish.
3. Work backward from the main sentence to the exhibit. Recalculate the unit conversion and check direction, precision, and how much interpretation the design supports. Correct any mismatch once and reread the affected sentence against the estimate.

**Deliver and stop** — Return the section and flag any interpretation that depends on an unresolved scale or reference group. Stop before commissioning another analysis. This run permits one initial pass and at most one targeted correction and recheck. A further round or another workflow needs a fresh human choice.

**Stay asleep for** — Estimate a new model or change the table layout.
