# Build a regression table

Shared rules · [Research exhibits and presentations](../research-exhibits/SKILL.md)

**Use when** — Turn model output into a paper-ready comparison.

**Do** — Put model specifications in columns and coefficients in rows, with uncertainty beneath estimates. Report baseline control coefficients, observations, fixed effects, and the appropriate fit statistic. Notes state clustering and star thresholds. For long mechanism or moderator tables, retain the focal main and interaction terms with the essential statistics.

**Don’t** — Transpose models into a horizontal list, hide baseline controls behind a generic Yes row, or expose software diagnostics as substantive rows.

**Check** — A reader can reconstruct the baseline specification and inference from the table, with pseudo-R-squared labelled correctly when used.

**Stay asleep for** — Interpret an existing estimate in manuscript prose.
