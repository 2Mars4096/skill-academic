# Formulate a mathematical problem

Shared rules · [Research discovery and design](../research-design/SKILL.md)

**Use when** — Express a substantive problem as a compact mathematical model.

**Do** — Define the notation, agents or decision variables, information, objective, constraints, and any timing or transitions the problem requires. Explain how each component maps to the stated problem and make the formulation complete enough to support later analysis.

**Don’t** — Expand a formulation request into a course manual, worked exercises, or an algorithm tutorial unless requested.

**Check** — The reader can interpret every symbol and identify the feasible decisions and criterion for comparing them.

**Stay asleep for** — Teach a course or implement a solver for an already specified model.
