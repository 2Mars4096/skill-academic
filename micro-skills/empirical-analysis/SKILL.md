# Empirical code and data

**Use when** — Construct, change, or reproduce an empirical analysis.

**Do** — Use the existing analysis as the starting point. Keep the unit of observation and the sample visible wherever the data change shape.

**Don’t** — Replace an established workflow to try a variation that can be run alongside it.

**Check** — The original result can still be reproduced and the new output has a traceable input and script.

**Stay asleep for** — Draft a paragraph describing an existing analysis without changing it.
