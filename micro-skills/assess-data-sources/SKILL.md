# Assess candidate data sources

Shared rules · [Research discovery and design](../research-design/SKILL.md)

**Use when** — Decide whether a source could support an analysis.

**Do** — Show what one record represents, key fields, population and time coverage, update frequency, and access. Use a sample record or the dictionary where available. Flag fields that would need to be constructed.

**Don’t** — Equate public documentation with access to the underlying observations.

**Check** — The reader can tell which variables are observed, what could be built, and what access or coverage still needs verification.

**Stay asleep for** — Document how the study’s final estimation sample was constructed.
