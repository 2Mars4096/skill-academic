## Applying the map

- **General default.** Use straightforward language. Include the detail needed to understand a result or take the next action. Remove commentary about the act of writing it.
- **Action rule.** When revising existing work, match the scope of the request. A wording correction, a formatting pass, and a change to the underlying analysis call for different edits.
- **Task rules.** Use the category’s shared instructions once and the relevant task’s instructions for the current step. If several outputs are requested, switch task skills as the work progresses.
- **Context exceptions.** Use project, audience, channel, language, or file restrictions when specified. The current request takes priority. A standing exception should name the rule and the behavior it changes. For an unresolved tie, record the override explicitly.

## Trying a skill

Every entry starts as **Draft**. Try it on a request matching **Use when**, then on the nearby request under **Stay asleep for**. Inspect the output against **Check**. If the result reflects the preference, the entry can be marked **Active**. A wrong activation or missed activation calls for a trigger edit. A correctly selected skill that gives the wrong output calls for an instruction edit. Conflicting instructions call for an explicit override.

The status records review decisions in this collection. Automatic activation depends on how the collection is connected to an agent.

## Basis and coverage

The rules generalize user-authored corrections, explicit instructions, and requested output formats in accessible Codex and ChatGPT chats. Task names, activation boundaries, and checks are editorial choices. Some narrowly scoped preferences, including the scheduling-message format, come from an individual request.

The review scanned 3,129 local Codex transcript files, including archives, duplicate records, and agent runs. It screened user turns in the main chats and used the app history to recover two partially readable transcripts. Three additional Codex chats listed by the app had no retrievable transcript. Across active and archived ChatGPT history, 203 of 386 listed chats were read through their available pages. The service rate-limited the remaining reads, including a retry. The collection contains generalized rules only.

A correction-focused review on 11 November 2026 read 25 Codex correction exchanges across 21 chats, including preceding user requests and assistant responses. It also consulted nine ChatGPT chats, with surrounding responses read for the selected email, research-question, and methodological-literature corrections. This pass revised 15 existing task skills, added four task skills, and strengthened the manager’s handling of corrections. The review covered selected exchanges and available text. Some referenced screenshots and attachments were unavailable. Generalized task rules omit historical project details.
