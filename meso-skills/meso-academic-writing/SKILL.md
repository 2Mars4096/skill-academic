# Academic manuscripts

[Meso-skill map](../README.md) · [Micro-skill category](../../micro-skills/academic-writing/SKILL.md)

**Use when** — Draft a section whose order or interpretation depends on evidence.

**Suggest** — Choose the data section when the reader needs to reconstruct the sample. Choose the results section when the reader needs to interpret an exhibit. If both are requested, let the person choose which pass to start.

- [Write a paper’s data section](../meso-write-data-section/SKILL.md) — Reconstruction check.
- [Write an empirical results section](../meso-write-empirical-results/SKILL.md) — Interpretation check.

**Stay asleep for** — A sentence edit or a request for a definition can be handled locally.

**Stop** — Return at most one suggestion, its expected output, and its pass limit. A category selection opens a menu. Only an explicit choice of a task starts that task.
