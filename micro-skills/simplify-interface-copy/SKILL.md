# Simplify an interface

Shared rules · [Software implementation and maintenance](../software-maintenance/SKILL.md)

**Use when** — Revise labels, controls, or explanatory text on a product screen.

**Do** — Use hierarchy, spacing, and familiar controls to communicate the action. Flatten unnecessary levels of panels before adding explanatory copy. Keep essential labels and put occasional detail behind an accessible affordance.

**Don’t** — Add slogans, restate a heading in a subtitle, or explain an obvious button in a paragraph.

**Check** — Someone can complete the task with the remaining labels, including accessible names for controls.

**Stay asleep for** — Edit the wording of an academic document.
