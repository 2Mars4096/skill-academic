# Software implementation and maintenance

**Use when** — Change or diagnose an existing application or repository.

**Do** — Begin with the workflow people already use. Identify the smallest change that satisfies the request and check it through that workflow.

**Don’t** — Add parallel systems, folders, or controls merely to accommodate a change the existing structure can express.

**Check** — The requested behavior is reachable from the user’s usual entry point.

**Stay asleep for** — Organize a replication package for an empirical paper.
