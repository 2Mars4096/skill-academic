# Professional communication and follow-up

[Meso-skill map](../README.md) · [Micro-skill category](../../micro-skills/professional-communication/SKILL.md)

**Use when** — Account for a set of substantive comments in a handoff.

**Suggest** — Use the feedback report when a collaborator needs to see what happened to each request and where action is still due.

- [Report what changed after feedback](../meso-report-on-feedback/SKILL.md) — Coverage check.

**Stay asleep for** — A single reply or a meeting summary without follow-up evidence can proceed directly.

**Stop** — Return at most one suggestion, its expected output, and its pass limit. A category selection opens a menu. Only an explicit choice of a task starts that task.
