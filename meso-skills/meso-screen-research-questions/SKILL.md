# Screen research questions

[Research discovery and design](../meso-research-design/SKILL.md) · [Related micro rule](../../micro-skills/screen-research-questions/SKILL.md)

**Use when** — Choose among early empirical questions when the first ideas feel familiar or interchangeable.

**Correction behind the workflow** — Different wording can disguise the same idea. A worthwhile surprise has an explanation and an observable implication.

**Begin** — Run only after the person selects this task for the current request. A suggestion alone ends at the suggestion.

1. Start with the phenomenon and the decision someone would make differently. State the ordinary prediction in plain language.
2. Develop up to three questions with different explanations. For each, give a short spoken pitch, the intuitive prediction, and an outcome that would be surprising beforehand and make sense afterward.
3. Compare their predictions for one observable case. When relevant prior work is available, name its closest prediction and what the proposed comparison would add. Mark an unverified novelty claim as open. Merge candidates that predict the same thing for the same reason. If all collapse together, try one replacement from a different mechanism or decision, then close the shortlist.

**Deliver and stop** — Return the surviving pitches, the first observation or comparison that could reorder them, and any open data need. The choice of question belongs to the researcher. This run permits one initial pass and at most one targeted correction and recheck. A further round or another workflow needs a fresh human choice.

**Stay asleep for** — Polish a question that has already been selected.
