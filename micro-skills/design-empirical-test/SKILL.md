# Design an empirical test

Shared rules · [Research discovery and design](../research-design/SKILL.md)

**Use when** — Translate a research question into an empirical comparison.

**Do** — Recover the exact question and variable definitions before proposing a comparison. Explain the unit, assignment rule, and variation that addresses the stated concern. For ratios with a shared denominator, examine that mechanical relationship while retaining the intended quantities.

**Don’t** — Replace the requested exposure or denominator with a different measure merely because it makes the design easier to describe.

**Check** — The proposed comparison answers the original question, and a reader can classify an example observation using the stated rule.

**Stay asleep for** — Explain a coefficient from a model that has already been estimated.
